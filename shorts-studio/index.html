Shorts Studio

Shorts Studio is a small personal desktop tool used by the YouTube channel RickGrimesz to edit Shorts and upload them to that channel.

It runs only on the owner's own computer. It is not offered to the public and has no user accounts.

It uses the YouTube Data API to upload videos, set their title and description, and post a comment, only after the owner presses "Post" and confirms.
