Privacy policy

Last updated: November 27, 2026

Shorts Studio is a personal tool that runs only on its owner's computer. It is used by one person to upload Shorts to their own YouTube channel.

What it accesses

After the owner signs in with Google, Shorts Studio can upload videos to the owner's YouTube channel, set their title, description and privacy, post a comment on them, and read the channel name to show which channel is connected.

Where data is kept

The Google sign-in token and all video files stay on the owner's computer. Nothing is sent to any server other than Google/YouTube. No data is sold, shared, or used for ads or tracking.

Use of Google data

Shorts Studio's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the Google Privacy Policy.

Removing access

Access can be removed at any time at myaccount.google.com/permissions, or with "Disconnect" inside the app, which deletes the saved token.
